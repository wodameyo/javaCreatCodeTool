# easyjava 优化与升级计划

> 版本：v1.0 · 2026-10-25
> 技术基线（已确认）：**Spring Boot 3.2 + Java 17** · **Vue 3 + Element Plus + Vite** · **MySQL 优先、元数据层预留扩展**

---

## 1. 背景与目标

`easyjava` 是一个"读 MySQL 表结构 → 生成一套后端 CRUD 代码"的脚手架工具，灵感来自 MyBatis-Plus 的代码生成器。当前实现以 `BufferedWriter` 拼接字符串生成代码，缺少抽象、缺少测试，且停留于 Spring Boot 2.6 / Java 8 时代；生成结果本身也存在多处会导致 SQL 报错或代码不可用的缺陷。

本次改造的目标：

| # | 目标 | 验收口径 |
|---|------|----------|
| G1 | 修复缺陷 | 生成的工程能编译、能启动、CRUD 与分页/模糊/时间区间查询真实可用 |
| G2 | 优化结构 | 配置、元数据、模型、模板、输出五层解耦；生成逻辑全部模板化，消除字符串拼接 |
| G3 | 升级功能 | Spring Boot 3.2 / Java 17 代码风格、构造器注入、RESTful、参数校验、事务、可选 Lombok / LocalDateTime / OpenAPI |
| G4 | 可视化界面 | Web 控制台完成"连库 → 选表 → 配置 → 预览 → 生成/下载 ZIP"闭环 |
| G5 | 前端代码生成 | 按表生成 Vue 3 + Element Plus + Vite 的列表/搜索/分页/新增/编辑/删除页面与请求层 |
| G6 | 可持续 | 单元测试 + 黄金文件测试 + Testcontainers 集成测试 + 生成结果编译验证 |

## 2. 现状评估

### 2.1 工程现状

- 根 `pom.xml` 为聚合工程，模块 `easyjava`（生成器）、`easyjava-demo`（生成结果演示）。
- 生成器无测试；`easyjava-demo` 仅有一个 `MapperTest`，且其中的产物是**旧版本生成结果**（`UserInfoMapper.xml` 仍为 `and id = #{query.userName}` 的错误写法）。
- 仓库根目录存在一个空的 `src/`，`target/` 产物被纳入工作区，说明构建与清理流程缺失。
- `easyjava-demo` 使用 Spring Boot 2.6.0 / Java 8；生成器模块声明 Java 8 但依赖 logback 1.4.x（要求 Java 11+），版本基线不一致。
- 配置文件 `application.properties` 中混用 `//` 注释（Java Properties 不支持），并明文保存数据库密码。

#### P2：结构 / 可维护性

- 11 个 `BuildXxx` 类各自实现一套 IO 与 import 逻辑，新增一种产物就要复制一份。
- `BuildComment.createMethodComment` 为空实现；注释换行符 `\n` 与 `newLine()` 混用，导致 CRLF/LF 混杂。
- 生成的 Controller 中存在大量未使用 import（`Serializable`、`Date`、`Mapper`、`@Service` 等）。
- `RunApplication` 只能全量生成，无参数、无日志、无摘要。
- 缺少生成清单输出（哪些文件新增/覆盖/跳过）。

## 3. 目标架构

### 3.1 模块划分

```text
javaCode/
├── pom.xml                      # 父 POM：Spring Boot 3.2 BOM、Java 17、依赖版本集中管理
├── easyjava-core/               # 生成引擎（不依赖 Web）
│   └── src/main/java/com/easyjava/core/
│       ├── config/              # GeneratorConfig / DataSourceConfig / OutputConfig / FrontendConfig
│       ├── metadata/            # MetadataReader SPI、JdbcMetadataReader、MySqlDialect、类型映射
│       ├── model/               # TableModel / ColumnModel / IndexModel（不可变）
│       ├── naming/              # 表名→类名、列名→属性名、模块名→URL
│       ├── template/            # FreeMarker 引擎与模板加载
│       ├── engine/              # CodeGenerator、GenerationPlan、GeneratedFile、FileWriter、ZipExporter
│       ├── cli/                 # RunApplication（保留命令行用法）
│       └── util/
├── easyjava-server/             # Web 控制台（Spring Boot 3.2）
│   └── src/main/java/com/easyjava/server/{controller,service,dto,config}
├── easyjava-ui/                 # 控制台前端（Vue 3 + Element Plus + Vite），构建产物复制到 server/static
├── easyjava-demo/               # 生成结果验证工程（Boot 3.2 + MySQL）
├── docs/
└── sample/schema.sql            # 覆盖各类字段的示例库脚本
```

职责边界：

| 模块 | 职责 | 不做什么 |
|------|------|----------|
| `easyjava-core` | 配置解析校验、元数据读取、模型构建、模板渲染、文件/压缩输出 | 不依赖 Spring MVC、不保存用户凭证 |
| `easyjava-server` | REST API、会话级数据源管理、预览/生成/下载、静态资源托管 | 不写生成逻辑 |
| `easyjava-ui` | 控制台交互 | 不直连数据库 |
| `easyjava-demo` | 作为生成产物的真实验证环境 | 不包含生成器代码 |

### 3.2 生成引擎流水线

```text
配置(YAML/JSON/表单)
   │  校验
   ▼
MetadataReader ──► TableModel[]（列/索引/注释/自增/可空/长度）
   │
   ▼
GeneratorContext（命名策略 + 类型映射 + 方言 + 模板变量）
   │
   ▼
TemplateEngine(FreeMarker) × 模板集（java / xml / vue）
   │
   ▼
GenerationPlan（文件清单：路径 + 内容 + 类型）
   │
   ├─► 预览（返回内容与 diff）
   ├─► 写盘（OVERWRITE / SKIP / BACKUP，含 dry-run）
   └─► ZIP 打包下载
```

### 3.3 技术选型

| 范畴 | 选型 |
|------|------|
| 语言/构建 | Java 17、Maven 3.9、UTF-8 |
| 基础框架 | Spring Boot 3.2.x（BOM 统一版本） |
| 持久层 | MyBatis 3.5.x + mybatis-spring-boot-starter 3.0.x（默认仍生成 XML 模式） |
| 数据库 | MySQL 8，`com.mysql:mysql-connector-j`；元数据统一走 `DatabaseMetaData` |
| 模板 | FreeMarker 2.3.x（成熟、无逻辑模板、易做黄金文件测试） |
| 序列化 | Jackson（由 Boot 管理），移除 fastjson |
| 文档 | springdoc-openapi 2.x（生成接口可选注解） |
| 测试 | JUnit 5 + AssertJ + Testcontainers(MySQL) + `javax.tools.JavaCompiler` |
| 控制台前端 | Vue 3.4 + Vite 5 + TypeScript 5 + Element Plus 2.8 + Vue Router 4 + Pinia + Axios |
| 生成的前端 | 同上（不含 Pinia，保持最小依赖；需要状态时再加） |

## 4. 功能设计

### 4.1 后端代码生成升级

#### 4.1.1 模板化产物清单

| 产物 | 模板 | 说明 |
|------|------|------|
| Entity(PO) | `po.java.ftl` | 可选 Lombok；日期类型可选 `Date` / `LocalDateTime`；`@JsonFormat` / `@DateTimeFormat` |
| Query | `query.java.ftl` | 继承 `BaseQuery`；字符串自动生成 `XxxFuzzy`；日期生成 `XxxStart/XxxEnd` |
| Mapper 接口 | `mapper.java.ftl` | `interface XxxMapper extends BaseMapper<Xxx, XxxQuery>`（非泛型声明） |
| Mapper XML | `mapper.xml.ftl` | 修复别名/分页/排序/主键回填；方言片段化 |
| Service 接口 | `service.java.ftl` | CRUD + 分页 + 按唯一键操作 |
| Service 实现 | `serviceImpl.java.ftl` | 构造器注入、`@Transactional`、分页结果正确填充 |
| Controller | `controller.java.ftl` | RESTful、`@RequestBody`、校验、OpenAPI（可选） |
| 基础类 | `base/*.ftl` | `BaseMapper`、`BaseQuery`、`SimplePage`、`PageSize`、统一响应、异常、全局异常处理 |

#### 4.1.2 生成接口约定（前端代码生成依赖此契约）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/{module}/page` | 分页列表，参数为 Query 字段 |
| GET | `/api/{module}/{id}` | 按主键查询 |
| POST | `/api/{module}` | 新增（JSON body） |
| PUT | `/api/{module}/{id}` | 按主键更新（JSON body） |
| DELETE | `/api/{module}/{id}` | 按主键删除 |
| POST | `/api/{module}/batch` | 批量新增 |
| POST | `/api/{module}/batch/upsert` | 批量新增或更新 |
| GET | `/api/{module}/by-{uniqueKey}` | 按唯一键查询（每个唯一索引一组） |

- 响应体保持 `ResponseVO{code, info, status, data}`；分页数据为 `PaginationResultVO{totalCount, pageSize, pageNo, pageTotal, list}`。
- `{module}` 默认由表名转 kebab-case（如 `user_info` → `user-info`）。
- 排序参数 `orderBy` 走**白名单**（仅允许 `列名 asc|desc`）。

#### 4.1.3 类型映射（可配置）

| MySQL | 默认 Java（Boot 3） | 兼容模式 |
|-------|--------------------|----------|
| tinyint(1) | Boolean | Integer |
| tinyint / smallint / mediumint / int | Integer | Integer |
| bigint | Long | Long |
| bigint unsigned / decimal(>18) | BigInteger | BigInteger |
| decimal / numeric / double / float | BigDecimal | BigDecimal |
| char / varchar / text / mediumtext / longtext | String | String |
| date | LocalDate | Date |
| time | LocalTime | Date |
| datetime / timestamp | LocalDateTime | Date |
| year | Integer | Integer |
| json / enum / set | String | String |
| bit | Boolean | byte[] |
| blob / binary / varbinary | byte[] | byte[] |

未识别类型：**记录告警并回退到 String**，不再中断整表解析。

#### 4.1.4 新增可配置能力

| 配置项 | 取值 | 默认 |
|--------|------|------|
| `backend.javaVersion` | 17 / 8（兼容模板） | 17 |
| `backend.lombok` | true / false | false |
| `backend.dateType` | `local` / `legacy` | `local` |
| `backend.apiStyle` | `restful` / `legacy` | `restful` |
| `backend.validation` | true / false | true |
| `backend.openapi` | true / false | false |
| `backend.transaction` | true / false | true |
| `backend.pagination` | `limit` | `limit` |
| `backend.overwritePolicy` | `overwrite` / `skip` / `backup` | `backup` |
| `backend.vo.envelope` | `responseVO` / `raw` | `responseVO` |

#### 4.1.5 命名与表过滤

- `ignorePrefix` 支持多个前缀（如 `tb_,t_`），按最长前缀匹配，而非当前"截取第一个下划线之后"。
- `includeTables` / `excludeTables` 支持通配符（`sys_*`）。
- 排除视图、排除无主键表（可配置为告警而非中断）。

### 4.2 可视化控制台

#### 4.2.1 页面

| POST | `/api/console/datasource/test` | 测试连接（仅校验，不落库） |
| POST | `/api/console/datasource/tables` | 返回表清单（会话级缓存连接参数） |
| POST | `/api/console/datasource/columns` | 返回指定表的列/索引详情 |
| POST | `/api/console/generate/preview` | 返回 `GenerationPlan`（路径 + 内容 + 是否已存在） |
| POST | `/api/console/generate` | 执行生成，返回摘要 + `downloadToken` |
| GET | `/api/console/generate/download/{token}` | 下载 ZIP |
| POST | `/api/console/generate/plan/diff` | 与磁盘文件比对（可选） |
| GET | `/api/console/config/defaults` | 默认配置 |
| GET | `/api/console/health` | 健康检查 |

#### 4.2.3 安全约束

- 服务默认仅绑定 `127.0.0.1`，端口可配。
- 数据库密码只在当前会话内存保存，不写日志、不回显；响应中脱敏。
- 日志中禁止输出完整 JDBC URL 中的密码参数。
- 写入磁盘前必须校验目标路径在允许根目录内（防路径穿越）。
- ZIP 下载 token 短时效、一次性。

### 4.3 前端代码生成

#### 4.3.1 生成物

```text
frontend/
├── package.json / vite.config.ts / tsconfig*.json / index.html / .env.development
└── src/
    ├── main.ts / App.vue
    ├── router/index.ts                 # 汇总所有表路由
    ├── utils/request.ts                # axios 封装（统一 ResponseVO 处理）
    ├── types/{module}.ts               # 实体 / Query / 分页结果类型
    ├── api/{module}.ts                 # 接口函数
    └── views/{module}/
        ├── index.vue                   # 列表页：搜索区 + 表格 + 分页
        └── components/{Entity}Form.vue # 新增/编辑弹窗 + 校验
```

- **脚手架文件只生成一次**：已存在时默认跳过（`skip`），避免覆盖用户定制。
- **路由与菜单**：为每张表生成独立路由配置片段，汇总到 `router/index.ts`；若文件已存在，追加标记块（`// <easyjava:table name="user_info">`）便于增量更新。
- 页面能力：关键字模糊搜索、日期区间、分页、排序、新增/编辑表单（必填/长度/类型校验）、删除确认、批量删除（可选）、请求 loading 与错误提示。
- 字段控件映射：`varchar`→`el-input`、`text`→`el-input type=textarea`、数字→`el-input-number`、`date`→`el-date-picker(date)`、`datetime`→`el-date-picker(datetime)`、`boolean`→`el-switch`、`enum`→`el-select`（枚举值来源可选注释解析或配置）。
- API base 路径可配（默认 `/api`），开发态通过 Vite proxy 指向后端。

#### 4.3.2 可选开关

| 配置项 | 说明 |
|--------|------|
| `frontend.enabled` | 是否生成前端 |
| `frontend.typescript` | TS / JS |
| `frontend.scaffoldOnly` | 仅生成脚手架，不生成业务页 |
| `frontend.packageManager` | npm / pnpm（影响 README 与锁文件说明） |
| `frontend.overwritePolicy` | 与后端一致 |

### 4.4 配置模型示例

```yaml
easyjava:
  datasource:
    url: jdbc:mysql://localhost:3306/demo?useSSL=false&serverTimezone=Asia/Shanghai
    username: root
    password: ${DB_PASSWORD:}
  output:
    backend-dir: ./easyjava-demo/src/main/java
    resources-dir: ./easyjava-demo/src/main/resources
    frontend-dir: ./easyjava-demo-ui
    overwrite-policy: backup
  generator:
    author: zcs
    package-base: com.example.demo
    table:
      include: []
      exclude: ["sys_*"]
      ignore-prefix: ["tb_", "t_"]
    backend:
      java-version: 17
      lombok: false
      date-type: local
      api-style: restful
      validation: true
      openapi: false
      transaction: true
    frontend:
      enabled: true
      framework: vue3-element-plus
      typescript: true
      api-base-path: /api
```

> 配置文件由服务端与 CLI 共用；控制台表单生成的值即此模型，避免"两套配置"。

## 5. 分阶段实施计划

> 原则：每个阶段结束都必须处于"可构建、可验证"状态；不跨阶段堆叠未验证改动。

### Phase 0：基线修复与可构建（P0）

**任务**
1. 重建父 POM：Java 17、Spring Boot 3.2 BOM、依赖版本集中管理；移除无用的 `target/` 与空 `src/`。
2. `easyjava` 模块升级依赖（logback 1.5.x / slf4j 2.0.x / 移除 fastjson），保证 `mvn clean compile` 通过。
3. 修复 B-01 ~ B-13（SQL 别名、分页、排序、主键回填、模板加载、输出路径、类型映射、toString、双分号、DateUtils、泛型、换行）。
4. 配置改为 YAML + 环境变量；删除明文密码；修正 `//` 注释；启动时做配置校验。
5. 增加最小可用测试：命名策略、类型映射、黄金文件（每个模板一个用例）。
6. 重新生成 `easyjava-demo` 并删除旧产物，接入 `mvn compile` 验证生成代码可编译。

**退出条件**
- `mvn -q clean test` 通过。
- 用示例库生成 demo 后，`easyjava-demo` 可编译启动。
- 列表分页、模糊搜索、时间区间、按主键/唯一键 CRUD 的实际 HTTP 调用全部成功。

### Phase 1：生成引擎重构

**任务**
1. 引入 `GeneratorConfig` + 校验器；废弃可变 `Constans`。
2. 元数据层抽象：`MetadataReader` + `MySqlDialect` + `DatabaseMetaData` 实现；类型映射注册表；索引按 `seq_in_index` 排序；表过滤。
3. 模型层：不可变 `TableModel` / `ColumnModel` / `IndexModel` / `GenerationContext`。
4. 模板层：FreeMarker 引擎、模板目录、共享宏（import 管理、注释、getter/setter、分页）；把 11 个 Builder 全部替换为模板。
5. 输出层：`GenerationPlan`、`FileWriter`（覆盖策略 + dry-run + 备份）、`ZipExporter`、生成摘要。
6. CLI：`RunApplication` 支持 `--config`、`--tables`、`--dry-run`、`--zip`。

**退出条件**
- `builder` 包内不再有逐字符拼接代码；新增一种产物只需新增模板。
- 黄金文件测试覆盖全部模板；CLI 与后续 Server 共用同一 `CodeGenerator`。

### Phase 2：可视化控制台

**任务**
1. 新建 `easyjava-server`（Boot 3.2），实现 4.2.2 的 API。
2. 会话级数据源管理（连接参数只存内存、超时淘汰、测试连接）。
3. 预览与生成：文件树、内容、已存在标记、覆盖策略、ZIP 下载。
4. `easyjava-ui` 实现数据源/表选择/配置/预览/生成 5 个页面，构建产物打入 server 静态资源。
5. 本地安全约束（绑定 127.0.0.1、路径白名单、密码脱敏、日志脱敏）。

**退出条件**
- 浏览器完成"填连接 → 选表 → 配置 → 预览 → 下载 ZIP"全流程。
- 服务端无生成逻辑重复实现；所有生成均调用 core。

### Phase 3：前端代码生成

**任务**
1. 设计 Vue 模板集：脚手架、`request.ts`、类型、API、列表页、表单弹窗、路由汇总。
2. 字段→控件映射、搜索区映射（Fuzzy/Start/End）、表单校验规则（必填/长度/数字范围）。
3. 多表路由与菜单的增量合并策略（标记块）。
4. 接入后端契约（`ResponseVO` / `PaginationResultVO` / RESTful 路径）。
5. 黄金文件测试 + 生成工程 `npm install && npm run build` 冒烟。

**退出条件**
- 示例库 3 张表一键生成前后端，前端工程可构建。
- 启动 demo 后端 + 生成的前端，列表分页/搜索/新增/编辑/删除均可用。

### Phase 4：质量、交付与增强

**任务**
1. Testcontainers 集成测试：建示例库 → 生成 → 编译生成源码 → 启动 Boot 上下文 → 调接口断言。
2. 前端生成物构建冒烟纳入 CI；黄金文件变更需评审。
3. 打包：`easyjava-server` 可执行 jar（前端内置）；`easyjava-core` CLI 可执行。
4. 文档：README（快速开始、配置说明、模板扩展指南）、`sample/schema.sql`、生成产物说明。
5. 可选增强（按优先级）：MyBatis-Plus 模式（`BaseMapper<T>`）、逻辑删除、审计字段自动填充、乐观锁 `version`、多数据源模板、PostgreSQL Dialect。

**退出条件**
- 一键构建 → 一键生成 → 一键运行 demo 的完整链路可复现。
- CI 全绿；文档覆盖新手路径。

## 7. 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 从字符串拼接改为模板，改动面大 | 生成结果回归 | 黄金文件测试先行；Phase 0 先固化当前期望输出（修正后） |
| Java 8 → 17、Boot 2 → 3 | demo 无法直接运行 | demo 独立升级；生成器提供 17/8 两套模板开关，默认 17 |
| 生成的前端与后端契约漂移 | 页面不可用 | 契约集中在 `ApiContract` 模板变量，前后端由同一模型渲染 |
| MySQL 方言硬编码 | 后续接 PG 困难 | 方言层隔离 SQL 片段；Phase 4 再接第二种库 |
| 覆盖用户手改代码 | 代码丢失 | 默认 `backup`，生成前预览 + 差异提示 |
| 控制台泄露数据库凭证 | 安全事故 | 内存会话、脱敏、本地绑定、日志过滤、禁持久化 |
| 无主键/无唯一键表 | 生成方法语义错误 | 生成前检测并告警；无主键不生成按主键方法，无唯一键不生成 upsert |
| 大表/多库一次性生成耗时 | 控制台超时 | 预览与写盘分离；生成任务异步化 + 进度（可选） |
